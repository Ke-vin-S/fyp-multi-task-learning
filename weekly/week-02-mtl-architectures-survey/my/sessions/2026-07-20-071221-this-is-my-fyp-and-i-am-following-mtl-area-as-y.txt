  Task Relationship Learning Upgrades for wavCSE

  Level 1: Drop-in (modify one file, no architecture changes)

  1. Gradient-based task affinity monitoring (TAG/Grad-TAG)

  What: Compute a 3×3 affinity matrix between content/speaker/emotion during
  training. After each epoch, measure how each task's gradient affects other
  tasks' losses.

  Where: Add to downstream/trainer/trainer_model.py — hook into the training
  loop after loss.backward().

  # After computing per-task losses, before backward:
  grad_i = torch.autograd.grad(loss_i, shared_params, retain_graph=True)
  # Measure: does grad_i improve or hurt loss_j?
  affinity[i][j] = loss_j_before - loss_j_after_applying_grad_i

  Value: Standalone publishable result. First quantitative evidence of which
  speech tasks help/hurt each other. ~50 lines.

  ---
  2. Random loss weighting baseline (RLW)

  What: Replace loss_weight = 1.0 / num_tasks with weights sampled from a
  Dirichlet distribution each batch.

  Where: downstream/trainer/trainer_model.py, the loss aggregation line (~line
  184 in the training loop).

  # Current:
  loss_weight = 1.0 / float(self.num_tasks)

  # RLW:
  w = torch.distributions.Dirichlet(torch.ones(num_tasks)).sample()
  total_loss = sum(w[i] * task_losses[i])

  Value: Essential baseline. If your fancy method doesn't beat this, it's not
  worth publishing. ~10 lines.

  ---
  3. Learned task relationship matrix on classifier heads (Kanakis et al., ECCV 
  2020)

  What: Add an m×m learnable correlation matrix Ω between the per-task
  classifier weights. Ω_ij captures how much task i's head shares statistical
  strength with task j.

  The core difference in one sentence: MTRL learns a parameter covariance V
  (statistical — "do these tasks' optimal weights correlate?"), while Grad-TAG
  learns a gradient affinity matrix A (dynamical — "do these tasks' gradients
  fight or agree?"). They measure fundamentally different things.

  Key findings for your presentation:

  │                │ (Bayesian prior)           │  gradient signals        │
