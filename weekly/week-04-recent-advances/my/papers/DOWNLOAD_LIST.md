## Download Tips

1. Most papers on arxiv → use "Download PDF" or `wget https://arxiv.org/pdf/{ID}.pdf`
2. Conference papers → check openreview.net (ICLR, NeurIPS) or CVF (CVPR, ICCV, ECCV)
3. Paywalled → check author homepages or use institutional access
4. File naming convention: `{Year}_{FirstAuthor}_{ShortTitle}.pdf` (e.g., `2024_Li_Grad-TAG.pdf`)
