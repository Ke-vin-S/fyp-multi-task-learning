2. Reference Papers & Key Ideas

[1]
Zhang, Graepel & Herbrich (2010) — Bayesian Online Learning for Multi-label and Multi-variate Performance Measures. AISTATS.
Key Idea A shared global bias couples all classes through a graphical model (similar to TrueSkill). The global bias acts as a "hub" parameter — updated more frequently than per-class weights — leading to more confident estimates and improved macro-averaged F1 scores over independent per-class training.
[2]
Ciliberto, Rosasco & Villa (2015) — Learning Multiple Visual Tasks while Discovering their Structure. CVPR.
Key Idea Each task predictor is a sparse linear combination of latent basis functions via a learned structure matrix A. ℓ1 regularization on A recovers only the most relevant task relations, preventing negative transfer. Alternating minimization with convergence guarantees: supervised step (learn f given A) → unsupervised step (learn A given f).
[3]
Gonçalves, Das, Chatterjee, Sivakumar, Von Zuben & Banerjee (2016) — Multi-task Sparse Structure Learning. CIKM.
Key Idea A sparse precision (inverse covariance) matrix Ω over task parameters captures conditional independence between tasks. Ωij = 0 means tasks i and j are conditionally independent given all others. The precision matrix is learned jointly with task parameters via alternating minimization. Two variants: p-MSSL (on parameters) and r-MSSL (on residuals).

3. wavCSE-GBC: Global Bias Coupling

3.1 Original Paper Idea

Zhang et al. (2010) proposed BOMC (Bayesian Online Multi-label Classification), where a global bias b couples all classes through a factor graph. In their multi-label model (Figure 3 of the paper), each class's discriminant dc = fc - b is compared against a shared global bias rather than independently thresholded. The global bias serves as a "hub" that is updated by every training example, leading to higher precision estimates.

Empirical finding: The coupled BOMC model (with global bias) significantly outperformed the independent per-class model (BOMC IND) on industries and regions groups of Reuters-1v2, with up to ~6% relative improvement in macro-averaged F1.

3.2 Mapping to wavCSE

Zhang 2010 ConceptwavCSE-GBC Implementation
Global bias b couples all classes global_bias parameter (dim=64) shared across all task heads
Per-class discriminant dc = fc - b Per-task logit = Wt·h + bt + projt(bglobal)
Global bias updated by every example Global bias receives gradients from all tasks in every batch
Bayesian treatment via Gaussian posterior Implicit: the global bias learns a data-dependent prior over task biases

3.4 Forward Pass

For each task t:

logitst = Wt · h + bt + projt(bglobal + gb_proj(h))

where:

  • Wt: task-specific weight matrix (unchanged from original)
  • bt: task-specific learned bias (new — was part of Linear, now explicit)
  • bglobal: global coupling bias (new, learnable, dim=64)
  • gb_proj(h): input-dependent global bias projection (new)
  • projt: per-task linear map from global bias space → task output space (new)

3.5 Design Rationale

DecisionReasoning
Global bias dim = 64 Small enough to act as a bottleneck (forcing shared information), large enough to carry meaningful coupling signal across diverse tasks (KS=12 classes, SI=1251, ER=4)
Both static + dynamic bias The static b_global captures dataset-level base rates (like Zhang's global b); the input-dependent gb_proj(h) captures per-sample coupling
Per-task projections (projt) Different tasks have different numbers of output classes; the projection maps the shared 64-dim coupling to each task's specific output space
Bias-only coupling (not weights) Coupling only biases (not weight matrices) is the minimal change — it models shared base rates while letting each task learn its own decision boundaries

4. wavCSE-TSM: Task Structure Matrix

4.1 Original Paper Idea

Ciliberto et al. (2015) proposed Sparse Kernel MTL, where each task predictor ft decomposes as a linear combination of latent basis functions gs through a structure matrix A:

ft(x) = Σs Ats · gs(x)

The matrix A is learned with ℓ1 sparsity to recover only the most relevant task relations. The optimization alternates between a supervised step (learn predictors given A) and an unsupervised step (learn A given predictors). This was shown to recover interpretable task clusters (e.g., natural vs. urban scenes in the 15-Scenes dataset) and resist negative transfer on Animals with Attributes.

4.2 Mapping to wavCSE

Ciliberto 2015 ConceptwavCSE-TSM Implementation
Latent basis functions gs in RKHS latent_classifiers[k]: K linear layers that form a "classifier basis"
Structure matrix A (T × K) structure_matrix_A: learnable parameter, softmax-normalized over K
ℓ1 sparsity on A structure_sparsity_lambda * ||A||1 penalty in loss
Alternating minimization Every alternate_frequency epochs: freeze model, optimize A only
Separable kernel k(x,x')·A Implicit: shared backbone provides the "kernel" (representation), A operates on classifier space

4.4 Forward Pass

latentk = LatentClassifierk(h)     // [B, max_C] for k=1..K
Asoft = softmax(A, dim=1)     // [T, K] row-stochastic
logitst = Σk Asoft[t,k] · latentk[:out_dimt] + bt

where K is the number of latent classifiers (default: 8), T is the number of tasks, and the softmax ensures each task is a convex combination of latent classifiers.

4.6 Design Rationale

DecisionReasoning
K=8 latent classifiers Enough to capture diverse task groupings (content, speaker, emotion clusters) without over-parameterizing. Similar to Ciliberto's T=10-20 task settings
Softmax over K (not raw A) Makes each task a convex combination of latents — interpretable as "task t uses X% of latent k". Also stabilizes training.
Alternate every 5 epochs Too frequent (every epoch) = structure oscillates; too infrequent = structure lags. 5 epochs balances both, matching Ciliberto's empirical schedule
Sparsity on A via l1 Core insight from Ciliberto: sparsity prevents negative transfer by zeroing out spurious task correlations. Only statistically meaningful relations survive.
Separate structure optimizer Different learning rate for A (0.001) vs model (0.0025). Structure learning needs smaller, more careful steps to avoid collapsing to uniform.

5. wavCSE-PMR: Precision Matrix Regularization

5.1 Original Paper Idea

Gonçalves et al. (2016) proposed MSSL (Multi-task Sparse Structure Learning), which learns a sparse precision matrix Ω (inverse covariance) over task parameters. The core insight: by modeling the rows of the parameter matrix W as draws from a multivariate Gaussian 𝒳j ~ N(0, Ω-1), the precision matrix Ω encodes conditional independence between tasks: Ωij = 0 means tasks i and j are conditionally independent given all others.

Empirical finding: On the landmine detection dataset, p-MSSL recovered two clear clusters corresponding to foliated (tasks 1-10) vs. desert (tasks 11-19) terrain, purely from data without any spatial information. On climate data, r-MSSL discovered meaningful spatial dependencies (Amazon basin connectivity, Andes separation).

5.2 Mapping to wavCSE

Gonçalves 2016 ConceptwavCSE-PMR Implementation
Precision matrix Ω (K×K) over tasks omega_chol: Cholesky factor of Ω, learned via gradient descent
-log|Ω| + Tr(WΩWT) get_pmr_loss(): log-det via Cholesky diag + trace via matrix multiply
λ||Ω||1 sparsity pmr_lambda * |off_diag(Ω)|1
γ regularization strength pmr_gamma: controls overall PMR loss contribution
Alternating minimization (W then Ω) Joint optimization with warmup: first 3 epochs no PMR, then enable
PSD constraint on Ω Enforced via Cholesky parameterization: Ω = LLT, L lower triangular

5.4 Loss Function

Ltotal = LCE + γ · (-log|Ω| + Tr(WΩWT)) + λ · ||off_diag(Ω)||1

Where each term has a specific role:

TermRolewavCSE-PMR Default
-log|Ω|Prevents Ω from collapsing to zero. Encourages well-conditioned precisionγ = 0.1
Tr(WΩWT)Couples task parameters: similar tasks get pushed together in parameter spaceγ = 0.1
λ||off_diag(Ω)||1Sparsity: only the most statistically meaningful task relationships surviveλ = 0.01

5.5 Design Rationale

DecisionReasoning
Cholesky parameterization Guarantees Ω is PSD by construction (Ω = LLT). Avoids expensive projection steps that ADMM-based methods (Gonçalves' original) require
Warmup epochs = 3 Let task heads converge to reasonable values before imposing structure. Without warmup, early PMR loss can force random task groupings
Off-diagonal sparsity only Diagonal of Ω represents task-specific precision (inverse variance) — should NOT be sparse (every task should have non-zero precision)
W from head weights + biases Flattening the full head parameters (weight matrix + bias vector) captures the complete task-specific parameterization in the trace term
γ = 0.1 (small) PMR is a regularizer, not the primary loss. Keep it small enough to guide without dominating. Gonçalves uses similar scaling

7.2 What We Changed & Why

ChangeApplies ToOriginalNewMotivation

7.3 Design Principles Followed

  1. Minimal invasiveness: All changes are confined to the task head region or loss function. The shared backbone, pooling, and feature extraction remain untouched.
  2. Drop-in compatibility: Each variant can be used with the same upstream embeddings, config system, and evaluation pipeline as original wavCSE.
  3. Interpretability first: Every added parameter has a clear meaning — global bias coupling (GBC), task-latent weights (TSM), conditional independence (PMR).
  4. Sparsity as a principle: Following both Ciliberto and Gonçalves, we use ℓ1 regularization to discover only statistically meaningful task relationships.
  5. Preserve original contributions: The Recursive Feature Selection (layer selection + frame/layer pooling) that makes wavCSE novel is not modified.
